# Logic Circuits

A digital logic course in seven labs. Each lab has three pages: Learn (animated lessons and interactive tools), Exercises (with worked answers) and Test yourself (multiple choice).

**Open the course: https://ahmedabdalmontalib.github.io/logic-circuits/**

You can also download `index.html` and open it in a browser. It works offline.

| Lab | Topic |
|---|---|
| 1 | Number Systems |
| 2 | Logic Gates |
| 3 | Boolean Algebra |
| 4 | Karnaugh Maps |
| 5 | Combinational Circuits |
| 6 | Flip-Flops |
| 7 | Counters and Registers |

Prepared by Dr. Ahmed M. AbdAl-Montalib, based on *A Course in Digital Logic and Design (CS102)*, Prof. Safwat Ahmed Aly, 2022.
